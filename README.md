# Project Title: Loan Portfolio Performance & Credit Risk Dashboard

### Objective

Analyze historical Lending Club loan data to evaluate portfolio performance, identify key risk drivers, and build an interactive executive dashboard.

### Tools Used

SQL (BigQuery)

Google BigQuery Sandbox

Looker Studio

Kaggle Lending Club dataset

### Key Findings

11.93% overall default rate

Grade G highest risk segment

Small business loans highest risk purpose

60-month loans riskier than 36-month loans
