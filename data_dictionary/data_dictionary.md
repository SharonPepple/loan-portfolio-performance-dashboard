# Data Dictionary (Loan Portfolio Dashboard)

| Column | Description |
|--------|-------------|
| issue_d | Month and year the loan was issued (e.g., Dec-2017) |
| loan_amnt | Loan principal amount issued |
| term | Loan term length (e.g., 36 months, 60 months) |
| int_rate | Interest rate assigned to the loan |
| grade | LendingClub assigned credit grade (A–G) |
| sub_grade | More granular credit grade (e.g., A1, B3) |
| purpose | Stated purpose of the loan (debt_consolidation, credit_card, etc.) |
| annual_inc | Borrower’s self-reported annual income |
| dti | Debt-to-income ratio |
| emp_length | Borrower employment length |
| home_ownership | Borrower home ownership status |
| verification_status | Whether borrower income was verified |
| addr_state | Borrower state (US) |
| loan_status | Loan status outcome (Fully Paid, Charged Off, Default, etc.)
